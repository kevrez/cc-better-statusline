# anim-frames.txt — animation frame definitions
#
# Format:
#   [name]    section header: animation name
#   frame     one frame per line
#   blank lines    ignored (use freely for readability)
#   # comments     ignored anywhere
#
# Editing: add, remove, or reorder frame lines to change an animation.
#   Changes take effect on the next statusline render — no restart needed.
#
# Width is inferred from the first and last frames automatically.
#   If the first frame is wider than 1 char, the statusline expands into it.
#   If the last frame is wider than 1 char, the statusline contracts out of it.
#   Animations that start and end at 1 char self-ramp through their own frames.
#
# Ordering here = fallback order when anim-playlist is missing or empty.
#   To control playback order, edit anim-playlist instead.
